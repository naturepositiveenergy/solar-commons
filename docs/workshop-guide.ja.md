# ソーラー・コモンズ：ワークショップ進行ガイド

ワークショップや授業、関係者の会合でソーラー・コモンズを使う進行役のためのガイドです。

**状況：** 英語版（[workshop-guide.md](workshop-guide.md)）を2026年11月6日に確認・承認済み。この日本語版はその翻訳です。

## 概要

- **プレイヤーがすること：** 日本の地方の町で太陽光発電所を開発します。早くて安い計画はすぐにお金になりますが、町の信頼と自然を損ない、町が太陽光条例を定めて、その後のすべての計画が難しくなることもあります。よい設計と住民との本当の対話による丁寧な計画は、時間はかかりますが高く評価されます。
- **参加者が持ち帰るもの：** 日本の太陽光発電で、地域の参加と自然に配慮した設計がなぜ大切か、そしてどのような実際の制度がその判断に関わるか。ゲーム内の「政策ノート」で、それぞれの制度を公的な出典とともに説明しています。
- **時間：** 1回のゲームは20〜30分。導入と振り返りを含めたセッション全体で60〜90分です。
- **人数：** 何人でも可能です。1台の端末を2〜3人で使うのがおすすめです。プレイヤー同士が判断について話し合うからです。
- **必要なもの：** 2〜3人に1台、最新のブラウザが入ったスマートフォン・タブレット・パソコン。進行役用のプロジェクター。アカウント登録、インストール、費用は不要です。
- **言語：** 日本語と英語。各プレイヤーが右上でいつでも切り替えられます。

## ワークショップの前に

1. **一度自分でプレイしてみてください。** 投影に使うパソコンで開きます：https://naturepositiveenergy.github.io/solar-commons/
2. **シナリオ番号を選びます。** 同じ番号で遊ぶと、全員に同じターンで同じ候補地が示され、同じ出来事が起こります。そのため、あとでグループ同士の結果を比べられます。1000〜9999のどの番号でも使えます。次の3つの番号は、ワークショップ向けに確認済みです：

   | 番号 | 特徴 | ターン1の候補地 | 出来事 |
   |---|---|---|---|
   | **1052** | 豪雨と系統接続 | ため池（促進区域）、森林の斜面、ブラウンフィールド | ターン5に制度変更（収入−20%）、ターン7と9に系統接続の遅れ、**ターン11に豪雨**、ターン14に他の事業者の開発、ターン18に台風 |
   | **7870** | 台風と他の事業者 | 営農型（促進区域）、ため池、ブラウンフィールド | ターン2に出力制御、ターン10と19に他の事業者の開発、**ターン11に台風**、ターン14に制度変更（収入−20%）、ターン17に系統接続の遅れ |
   | **1016** | 穏やかな展開（初心者や短いセッション向け） | ブラウンフィールド、営農型（促進区域）、耕作放棄地 | ターン3に出力制御、ターン7に系統接続の遅れ |

   ターン9からは、隣町でも候補地が示されます。ターン9の隣町の候補地は、1052が営農型とため池、7870がため池（促進区域）と森林の斜面、1016が耕作放棄地と営農型です。

   出来事は全員に同じように起こりますが、その影響はプレイヤーによって異なります。たとえば豪雨は、森林の斜面の発電所と、安価な工法で建設した発電所にだけ被害を与えます。台風は、外周の生け垣が3つ未満の発電所にだけ被害を与えます。ここから、振り返りの話し合いがおもしろくなります。

3. **シナリオ番号付きのリンクを用意します。** たとえば https://naturepositiveenergy.github.io/solar-commons/?code=1052 。このリンクから開くと、スタートボタンが「シナリオ 1052 を始める」になります。QRコードは、パソコンのChromeでリンクを開き、ページを右クリックして **「このページの QR コードを作成」** を選ぶと作れます（Chromeのバージョンによっては、アドレスバーの **共有** メニューにあります）。リンクとQRコードを最初のスライドに載せておきましょう。
4. **できれば会場のWi-Fiを確認してください。** インターネットが必要なのは、各端末で最初にゲームを開くときだけです。その後はオフラインでも遊べます。

## 会場で：始め方（約5分）

1. QRコードとリンクを見せます。参加者はリンクを開いて **「シナリオ 1052 を始める」**（または選んだ番号）を押します。リンクを使わない場合は、スタート画面の **「シナリオ番号で遊ぶ」** を押して番号を入力します。
2. 全員に次の2点を確認してもらいます：
   - スタート画面に **「この端末では、インターネットがなくても遊べます。」** と表示されていること。これでWi-Fiが弱くても大丈夫です。
   - ゲーム中、ステータスバーの下に **「シナリオ 1052」** と表示されていること。違う番号のグループは、ランダムなゲームを始めています。**「タイトル」** を押して、もう一度番号から始めてもらいます。
3. 初めてのプレイヤーには、画面上部に「次にすること」のヒントが表示され、最初の発電所づくりを案内します。上部の **「遊び方」** では、ルールを6つの短い項目で説明しています。

## セッションの進め方（例）

**75分の場合**

| 時間 | 内容 | メモ |
|---|---|---|
| 0:00 | 導入（10分） | 日本の太陽光発電の拡大と、それに伴う問題：森林の斜面での土砂災害、景観、相談されなかった住民、地域の条例。ゲームの目標。 |
| 0:10 | 開始（5分） | リンクまたはQRコード、シナリオ番号、「インターネットがなくても遊べます」の確認。 |
| 0:15 | プレイ（30分） | 会場を回り、ペアに「なぜその候補地や設計を選んだのか」を聞いてみましょう。0:35に残り時間を伝えます。 |
| 0:45 | 結果の集計（5分） | 下の「結果を比べる」を参照。 |
| 0:50 | 振り返り（20分） | 下の問いを参照。 |
| 1:10 | まとめ（5分） | 政策ノートを参考資料として紹介し、家でも遊べるリンクを伝えます。 |

**60分の場合：** 導入5分、振り返り15分にして、番号 **1016** を使います。

**90分の場合：** 最初の振り返りのあと、同じシナリオをもう一度遊びます（終了画面の **「このシナリオでもう一度遊ぶ」**）。このとき戦略を決めておきます。たとえば半分のグループは「早くて安い」、残りは「丁寧に」で遊び、結果を比べます。2回目は操作に慣れているので、20〜25分ほどで終わります。

## 結果を比べる

- 終了画面の **「結果をコピー」** を押すと、短いまとめがコピーされます。普段使っているチャットや共有文書に貼り付けてもらいましょう。たとえば次のようになります（数値は例）：

  > ソーラー・コモンズ – シナリオ 1052
  > 評価 A（優秀）、発電所の平均点 14点中11.5点
  > 建設した発電容量 22.4 / 15・資金 63.0・信頼 68・評判 61
  > プロジェクト1・ブラウンフィールド（工場跡地など）・14点中13点：立地の選択 ○、自然への取り組み ○、…

- 共有文書がない場合は、各グループに評価（S・A・B・C・D）を聞いて、ホワイトボードに集計します。そのうえで、評価が最も高いグループと最も低いグループに、何が違ったのかを聞いてみましょう。
- ブラウザによってはコピーできないことがあります。その場合は、ボタンの下の欄にまとめが表示されるので、選択して手動でコピーします。

## 振り返りの問い

3〜4問を選んでください。かっこ内の政策ノートの項目に、出典付きの実際の背景があります。政策ノートは、スタート画面とゲーム中の **「政策ノート」** から開けます。

**結果**
- どの評価でしたか。同じシナリオで、最もよかったグループと最も苦労したグループは、何が違いましたか。

**速さと丁寧さ**
- 安価な工法や密なパネルを試した人はいますか。その後、何が起こりましたか。
- あるグループのいいかげんな計画が条例につながると、その後は丁寧な計画も含めて、すべての計画が難しくなります。「早くて安い」のつけを払うのは誰でしょうか。（*太陽光発電に関する条例*）
- ターン9から、隣町のあなたへの信頼は、地元の町での信頼と同じところから始まりました。隣町で有利なスタートを切ったのは誰でしょうか。一方の町で警告を受けたとき、もう一方の町の信頼はどうなりましたか。（*太陽光発電に関する条例*）

**地域**
- 一番支持を得にくかった住民は誰ですか。何が効果的でしたか。
- 法律で定められた説明会だけでなく、対話型の説明会を開くと、何が変わりましたか。（*住民説明会（再エネ特措法）*）
- 市民ファンドを使った人はいますか。地域の人が発電所の一部を所有すると、何が変わるでしょうか。（*市民出資*）

**自然と設計**
- どのような自然への取り組みをしましたか。生け垣や生きものの通り道は、数だけでなく、どこに置くかがなぜ大切なのでしょうか。（*自然共生サイト*）
- 森林の斜面はなぜリスクが高いのでしょうか。森林を選んだ人は、豪雨のとき何が起こりましたか。（*林地開発許可*）
- 営農型太陽光発電の利点と難しさは何でしょうか。収穫不十分で指導を受けた人はいますか。パネルの下の光は、なぜ大切なのでしょうか。（*営農型太陽光発電（一時転用）*）

**同じシナリオ、違う結果**（番号1052と7870）
- ターン11に、豪雨（1052）または台風（7870）が全員を襲いました。誰の発電所が被害を受け、ほかの人はなぜ受けなかったのでしょうか。

**ゲームから現実へ**
- 促進区域に建設した人はいますか。町はなぜ促進区域を定めるのでしょうか。（*促進区域（地域脱炭素化促進事業）*）
- 2027年度（ターン5）の前に、急いで申請した人はいますか。それは得でしたか。どのような太陽光発電の事業が、これからも公的な支援を受けるべきでしょうか。それはなぜでしょうか。（*固定価格買取（FIT）と市場連動（FIP）*）
- 自分の町でよい太陽光発電の計画を進めるには、何が必要でしょうか。最初から誰が話し合いに加わるべきでしょうか。
- 何が意外でしたか。

## ヒント

- **2〜3人で遊ぶと会話が生まれます。** その会話こそが、ワークショップで一番大切な部分です。
- **早く終わったグループ**は、**「このシナリオでもう一度遊ぶ」** を押して、別の戦略を試せます。
- **プレイヤーがつまずきやすいところ：**
  - 許可が下りたのに、資金が足りず建設が始まらない。プロジェクトのカードに表示されます。収入を待つか、もっと安い発電所を計画しましょう。
  - 許可の手続き中に、そのターン住民と対話しなかったため支持が下がる。ヒントとプロジェクトのカードが注意を促します。
  - 営農型の発電所が、収穫不十分で指導を受ける。プロジェクトのカードに説明があります。次の年度末までにパネルを間引きましょう。
  - 資金が2ターン続けてマイナスになる、または信頼が5を下回ると、ゲームオーバーです。これも振り返りのよいきっかけになります。
- **ゲームはブラウザに自動で保存されます。** うっかりページを閉じても、もう一度リンクを開いて **「続きから遊ぶ」** を押せば大丈夫です。
- **端末を共有する場合：** 次のグループのために、**「タイトル」** を押してから **「新しいゲーム」** を押すか、リンクを開き直します。保存されているゲームを上書きする前に、確認の画面が出ます。
- **プロジェクターでは、** **Ctrl と +**（Macは **Cmd と +**）で拡大できます。文字が大きくなっても、画面の配置は自動で調整されます。

## 困ったとき

| 問題 | 対処 |
|---|---|
| ページが開かない | リンクとWi-Fiを確認します。別のブラウザ（Chrome、Safari、Edge、Firefox）を試します。 |
| あるグループだけ候補地が違う | ステータスバーの下のシナリオ番号を確認し、リンクまたは番号から始め直します。 |
| 「インターネットがなくても遊べます」が表示されない | インターネットにつながった状態で一度ゲームを開き、数秒待ちます。プライベートウィンドウでは、オフライン用のコピーが保存されないことがあります。 |
| 「結果をコピー」でコピーできない | ボタンの下に表示される欄から、文章をコピーします。 |
| 古いバージョンのゲームが表示される | インターネットにつながった状態で、ページを一度再読み込みします。 |
| 文字が小さくて読めない | Ctrl と +（Macは Cmd と +）で拡大します。 |

アプリとしてインストールする方法など、技術的な説明は [publishing.md](publishing.md)（英語）にあります。

## 内容について

- ゲームは意図的に単純化しています。数値はゲーム上の値で、実際の費用・発電量・許可期間ではありません。
- 政策ノートは、最後に確認した時点での日本の実際の制度を説明しています（[policy-notebook.md](policy-notebook.md) を参照）。制度は変わります。たとえば政府は、2027年度から10kW以上の新しい地上設置型太陽光発電をFIT・FIPの支援対象外とすることを決めましたが、例外（促進区域の事業など）については2026年秋の時点でまだ議論が続いていました。ルール v0.8 から、ゲームにもこれを反映しています：ターン5（2027年度）以降に申請したプロジェクトは、促進区域のボーナスがない限り、市場価格で売電します。例外についての最終的な決定（2027年1月ごろの見込み）が異なる場合は、ゲームを更新します。
- 上で紹介したシナリオ番号は、現在のバージョン（ルール v1.0）のものです。ルールが変わると展開も変わる可能性があり、その際はこのガイドを更新します。
